# Haykathon · Handbook des participants

Guide des participants du Haykathon, hackathon entrepreneurial communautaire d’un week-end, dans la salle paroissiale de la Cathédrale Sainte-Croix des Arméniens (Paris 3e).

Version officielle (production) : https://www.armeniencatholique.fr/haykathon/

Ce dépôt sert de préproduction, publiée avec GitHub Pages : https://jck-sabords.github.io/haykathon/ . Une fois validé, `index.html` est déposé sur le site officiel.
